# GENESIS — живая симуляция цивилизаций в браузере

Создайте мир и наблюдайте: племена основывают поселения, растут в царства и империи, торгуют, воюют, создают
веры и легенды, переживают засухи и мор, распадаются — и оставляют руины, которые через века найдут археологи.

Чистый TypeScript, Canvas 2D, Web Worker, IndexedDB, PWA. Без игровых движков и серверов.

## Запуск

```bash
npm install          # TypeScript, Vite, tsx
npm run dev          # разработка (Vite)
npm run build        # проверка типов + production-сборка в dist/
npm test             # тесты (node:test через tsx)
```

Без npm (есть только esbuild): `ESBUILD_PATH=/путь/к/esbuild node scripts/build.mjs` — результат тот же, `dist/`.

## Размещение (REG.RU и любой статический хостинг)

Загрузите **содержимое** папки `dist/` в любую папку сайта (например, `public_html/genesis/`). Пути относительные,
Node.js на хостинге не нужен. Для офлайн-режима и установки как приложения нужен HTTPS.

## Управление

Пробел — пауза · 1–4 — скорость · стрелки/WASD — карта · колёсико/щипок — масштаб · двойное касание — приблизить ·
C — хроника · E — энциклопедия · Esc — закрыть.
