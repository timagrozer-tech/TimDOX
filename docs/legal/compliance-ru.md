# Yarko — соответствие требованиям РФ: аудит и рекомендации

Редакция от 8 октября 2026 г. Это технический аудит, а не юридическое заключение. Пункты с пометкой **[юрист]** нужно проверить со специалистом по 152-ФЗ и 149-ФЗ до публичного запуска.

## 2. Безопасность (ст. 19 152-ФЗ, ПП № 1119)

Уже есть: хэш паролей scrypt, HTTPS и HSTS, CSP, защита от CSRF, ограничение частоты запросов, двухфакторная аутентификация с зашифрованным секретом, журнал входов (90 дней, без полного IP), очистка EXIF при загрузке, журнал действий администрации (только добавление на уровне прав в базе).

Рекомендации:
- задать `KRUG_SECRET_KEY` в Render, если ещё не задан (ключ шифрования секретов 2FA);
- включить резервное копирование с понятным сроком хранения и отразить его в Политике;
- определить уровень защищённости ИСПДн и меры по ПП № 1119 **[юрист]**;
- перенести шрифты Google на свой сервер — уйдёт передача IP в США при каждом открытии сайта.

## 4. Удаление данных пользователя

Аккаунт удаляется сразу и каскадно: профиль, публикации, комментарии, его сообщения во всех переписках, файлы, клипы, истории, стикеры, подписки и записи о согласиях. Выгрузка данных доступна в «Настройки» → «Ещё».

Открытые вопросы:
- нужно ли сохранять доказательства согласия после удаления аккаунта. Сейчас они удаляются вместе с аккаунтом **[юрист]**;
- срок хранения резервных копий у поставщика нужно вписать в Политику.

## 5. Cookie

Используются только необходимые cookie (`krug_session`, `krug_ref`). Рекламных и аналитических нет. Показывается информационная плашка, подтверждение сохраняется в журнал согласий.

## 6. ИИ-функции

Все шесть мест, где данные пользователя уходят нейросети, теперь работают только при согласии `ai`:
1. ИИ-помощник в чате;
2. ИИ-персонажи «Мира»;
3. ответы официального профиля на комментарии;
4. расшифровка голосовых (по согласию автора голосового);
5. стикеры по описанию и ИИ-подписи к фото-набору;
6. автоматические теги для стикеров (кроме публичных наборов из Telegram и встроенных).

Без согласия функции работают без ИИ.

Проверить: условия Groq об использовании данных API для обучения — вписать актуальную формулировку в `/ai-consent` **[юрист]**.
