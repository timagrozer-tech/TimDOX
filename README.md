# TimDOX — Excel → готовая справка в Word

Сайт, куда можно загрузить Excel-файл, добавить образец документа и получить готовую справку или доклад в формате Word (.docx). Работает на телефоне (Android и iPhone) и на компьютере, его можно установить на телефон как приложение.

ИИ по умолчанию работает **бесплатно через OpenRouter** (модель `openrouter/free`). По желанию можно переключиться на DeepSeek. Ключ хранится только на сервере, посетители сайта его не видят.

---

## Возможности

- Загрузка Excel/CSV (все листы), **несколько файлов сразу** для сравнения или **пример в один клик**, комментарий к файлу, в том числе голосом
- **Автосводка**: сайт сам считает суммы, средние, минимумы и максимумы, итоги по категориям и отдаёт ИИ уже точные цифры
- Готовые образцы (справка, доклад, аналитическая записка) и свои, в том числе из .docx
- **Настройки документа**: объём, стиль текста, оформление Word (деловое Times New Roman 14 или современное Calibri 11), таблицы, номера страниц, дата, реквизиты (организация, должность, ФИО)
- Предпросмотр в виде страницы Word во время генерации, редактирование, счётчик слов, автосохранение черновика
- **Диаграмма по данным**: строится автоматически и вставляется в документ и в Word с подписью «Рисунок 1 — …»
- **Проверка цифр**: каждое число в тексте сверяется с таблицей, а не найденные в данных подсвечиваются
- Скачивание .docx с настоящими таблицами, **печать и сохранение в PDF**, отправка файла в мессенджеры
- ИИ-помощник с быстрыми командами («Короче», «Официальнее», «Проверь цифры») и голосовым вводом
- Установка на телефон как приложение, тёмная и светлая тема

## Что внутри

```
timdox/
├── public/            ← сам сайт (интерфейс)
│   ├── index.html
│   ├── manifest.webmanifest, sw.js, icon-*.png   ← установка на телефон
│   └── vendor/        ← библиотеки для чтения Excel и сборки Word
├── lib/ai.js          ← связь с ИИ (OpenRouter / DeepSeek), лимиты, защита
├── api/               ← точки входа для хостинга Vercel
├── server.js          ← обычный сервер: node server.js
├── .env.example       ← пример настроек
└── vercel.json
```

Внешних зависимостей нет: нужен только Node.js 18 или новее.

## Шаг 1. Получите бесплатный ключ OpenRouter (3 минуты)

1. Зарегистрируйтесь на https://openrouter.ai (кнопка **Sign up**, подойдёт Google-аккаунт или почта). Карта не нужна.
2. **Обязательно:** откройте https://openrouter.ai/settings/privacy и включите **«Free model publication»**. Без этой настройки OpenRouter не пускает к бесплатным моделям, и сайт покажет ошибку «no endpoints found matching your data policy».
   Эта настройка означает, что провайдеры бесплатных моделей могут использовать запросы для обучения. Поэтому не загружайте в бесплатный режим секретные или персональные данные.
3. Откройте https://openrouter.ai/settings/keys → **Create API Key** → скопируйте ключ (начинается с `sk-or-`). Ключ показывается один раз, сохраните его.

Больше ничего настраивать не нужно: модель `openrouter/free` сама выбирает доступную бесплатную модель.

**Лимиты бесплатного режима** (общие на весь сайт, потому что ключ один):
- 20 запросов в минуту;
- 50 запросов в день; после разовой покупки кредитов на $10 лимит становится 1000 в день, а сами бесплатные модели остаются бесплатными.

Когда дневной лимит заканчивается, сайт так и пишет пользователю, а на следующий день всё снова работает. Бесплатные модели бывают перегружены, поэтому сервер при временной ошибке сам повторяет запрос один раз.

### Если бесплатного станет мало — DeepSeek
1. Ключ на https://platform.deepseek.com → **API Keys** и пополнение баланса.
2. В переменных окружения вместо `OPENROUTER_API_KEY` укажите `DEEPSEEK_API_KEY` (или добавьте `AI_PROVIDER=deepseek`).

API DeepSeek платный, но дешёвый: в сентябре 2026 г. модель `deepseek-flash` стоила $0.15 за 1 млн входных токенов и $0.60 за 1 млн выходных. Одна справка обходится меньше чем в 1 цент. Цены: https://api-docs.deepseek.com/quick_start/pricing

## Шаг 2. Выложите сайт в интернет

### Способ 1 — Vercel (бесплатно, проще всего)
1. Загрузите папку `timdox` в новый репозиторий на GitHub.
2. Зайдите на https://vercel.com → **Add New… → Project** → выберите репозиторий → **Deploy**.
3. В проекте: **Settings → Environment Variables**, добавьте одну переменную:
   - `OPENROUTER_API_KEY` = ваш ключ `sk-or-...`
4. **Deployments** → у последнего деплоя «⋯» → **Redeploy** (чтобы подхватились ключи).
5. Готово: сайт откроется по адресу вида `https://timdox.vercel.app`. Свой домен подключается в **Settings → Domains**.

### Способ 2 — любой VPS или хостинг с Node.js (в том числе российский)
```bash
# на сервере, в папке проекта
cp .env.example .env      # впишите ключ в .env
node server.js            # сайт будет на http://ваш-сервер:3000
```
Чтобы сервер работал постоянно, используйте `pm2`:
```bash
npm i -g pm2
pm2 start server.js --name timdox
pm2 save && pm2 startup
```
Если сервер стоит за nginx, в блоке `location` добавьте `proxy_buffering off;`, иначе текст будет появляться не постепенно, а весь сразу в конце.

Если у части пользователей не открывается адрес `*.vercel.app`, разместите сайт этим способом на своём домене.

### Способ 3 — Render (бесплатно, «засыпает» без посетителей)
https://render.com → **New → Web Service** → репозиторий → Start command: `node server.js` → в **Environment** добавьте те же переменные.

## Шаг 3. Проверьте
Откройте сайт: под заголовком должна быть зелёная метка **«ИИ подключён · OpenRouter · бесплатно»**. Красная метка означает, что ключ не указан или сервер его не видит.

Затем сгенерируйте тестовую справку. Если появилась ошибка про «Free model publication», вернитесь к пункту 2 шага 1.

## Настройки (переменные окружения)

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `OPENROUTER_API_KEY` | ключ OpenRouter | — |
| `DEEPSEEK_API_KEY` | ключ DeepSeek (если нужен платный режим) | — |
| `AI_PROVIDER` | `openrouter`, `deepseek` или `custom`; обычно не нужен, провайдер определяется по ключу | авто |
| `AI_MODEL` | имя модели, например конкретная бесплатная `...:free` с openrouter.ai/models | `openrouter/free` / `deepseek-flash` |
| `AI_BASE_URL` | адрес API (для `custom`, любой OpenAI-совместимый) | — |
| `ACCESS_CODE` | **код доступа**: если задан, ИИ работает только у тех, кто знает код. Защищает ваш баланс от посторонних | выключен |
| `RATE_LIMIT_PER_HOUR` | ИИ-запросов в час с одного IP (чтобы один человек не израсходовал дневной лимит на всех) | `30` |
| `MAX_INPUT_CHARS` | максимальный объём данных в запросе | `200000` |
| `MAX_OUTPUT_TOKENS` | максимальная длина ответа | `8000` |
| `SITE_URL` | адрес сайта (для статистики OpenRouter) | — |

💡 В бесплатном режиме 50 запросов в день делят все посетители сайта. Если сайтом пользуется много людей, уменьшите `RATE_LIMIT_PER_HOUR` или включите `ACCESS_CODE` и раздавайте код только своим.

## Установка на телефон
- **Android (Chrome):** на сайте появится кнопка «📲 Установить TimDOX как приложение» (или меню ⋮ → «Добавить на главный экран»).
- **iPhone (Safari):** «Поделиться» → «На экран Домой».

## Где хранятся данные
Excel-файлы и документы обрабатываются в браузере пользователя. На сервер ИИ уходит только текст таблицы и образца, когда пользователь нажимает «Сгенерировать». Образцы и история документов хранятся в браузере каждого пользователя, поэтому у каждого они свои.
